# SCOUT / STRIDE

실험 버전에는 아래쪽에서 출구 방향으로 추격하는 안개가 있습니다. 시작 후 2초 뒤 이동하며 기본 속도는 60 단위/초입니다. 플레이어 중심이 안개 안에 연속 2초 머물 때마다 체력 1을 잃고, 안개 밖으로 나오면 노출 시간이 초기화됩니다. 속도와 피해 간격은 시작 전에 설정할 수 있습니다. 안개 위치·노출 시간·피해 이벤트와 설정은 JSON에 저장하며, 안개 피해는 가시 접촉 수에 포함하지 않습니다.


별도 실험 버전: `exploration.html`을 열면 **정지 탐색 게임**이 실행됩니다. 원본 `index.html` / `game.js`는 그대로 유지됩니다. 정지 중에만 마우스 방향의 60도 시야가 기본 0.6초 동안 최대 거리 120까지 확장됩니다. 이동 중 주변 시야는 더 좁고, 주변·전방 시야의 가장자리는 흐려집니다. WASD와 방향키는 주시 방향 기준으로 전후진·좌우 이동합니다. 시야 방향의 최대 회전 속도는 기본 45도/초이며 제한 해제와 수치 조절이 가능합니다. 설정은 게임 시작 전에 변경합니다.

탐색한 바닥 구획의 밝기 잔상은 표시하지 않습니다. 발견한 고정 함정의 위치는 희미하게 남고, 관찰 이력 저장은 유지합니다. 기록에는 시야 방향·정지 탐색 상태·시야 거리·8 단위 셀의 최초 관찰 시간이 포함됩니다. 이 버전은 JSON 기록 저장을 지원하며, 실험 버전 기록의 리플레이와 stride/scout 자동 분류는 아직 제공하지 않습니다. 원본 리플레이는 원본 페이지에서 사용하세요. 검증: `node tests/exploration.test.cjs`.

`index.html`을 브라우저로 열면 실행됩니다. 빌드, 서버, 외부 라이브러리는 필요 없습니다. 정적 호스팅에는 `index.html`과 `game.js`를 함께 업로드하세요.

게임 화면은 브라우저의 가로 폭과 남은 높이를 사용합니다. 체력은 좌상단, 진행 정보와 조작 안내는 우상단, 기록 저장 버튼은 하단에 표시합니다. 리플레이에서는 조작 안내를 숨기며, 체력 아래에 행동 추정을 큰 글씨로 표시합니다.

대기 또는 종료 화면에서 Enter 키로 게임을 시작하거나 다시 시작할 수 있습니다.

상단의 **리플레이 파일 열기**에서 저장된 JSON 기록을 선택하세요. 재생/일시정지, 0.5~4배 배속, 시간 슬라이더를 지원합니다. 전체 동선을 선으로 표시하고 시야 범위는 점선 원으로 표시하며, 시야 밖의 가시도 화면에 보입니다. 위치·체력·함정 접촉·이동 거리는 기록된 시간에 맞춰 복원합니다. 게임 시작이나 초기화를 누르면 일반 게임으로 돌아갑니다. 리플레이 자체는 새 플레이 기록을 만들지 않습니다.

새 기록은 시야 설정도 함께 저장합니다. 시야 설정이 없는 이전 파일은 현재 설정으로 재생합니다.

리플레이의 행동 추정은 매 화면 프레임과 시간 이동 시 갱신합니다. 최근 1.5초 중 최소 1초의 기록을 기준으로, 출구 방향 순전진 거리 / 전체 이동 거리 ≥ 90%, 평균 전진 속도 ≥ 32, 움직인 시간 비율 ≥ 85%를 모두 만족하면 **stride**, 나머지는 **scout**입니다. 움직인 시간은 속도 1을 초과한 기록 구간으로 계산합니다. 걷기와 달리기 모두 stride가 될 수 있습니다. 재생 배속과 무관하게 기록의 시간을 기준으로 계산합니다. 표시 위에 마우스를 올리면 판정 지표를 볼 수 있습니다. 동선에 따른 간단한 분류이며 실제 탐색 의도나 위험 인식에 대한 판정은 아닙니다.

리플레이 검증: `node tests/replay.test.cjs`.

- 상단 미션 크기: 1~100개 구간. 구간 높이 224, 맵 너비 224, 플레이어 지름 32의 연속 좌표계를 사용합니다.
- WASD 또는 방향키 이동, 스페이스바 홀드 시 달리기. 각 방향은 두 입력의 논리합입니다(예: W 또는 ↑). 같은 방향의 키를 함께 눌러도 속도는 늘지 않으며, 한 키를 놓아도 다른 키가 눌려 있으면 해당 방향 입력은 유지합니다. Shift 홀드 시 감속 걷기 최대 속도는 30, 일반 걷기는 65, 달리기는 110입니다. Shift는 스페이스바보다 우선하며, 양쪽 Shift 중 하나라도 눌려 있으면 유지됩니다. 스페이스바를 놓으면 감속하여 걷기 속도로 돌아갑니다. 대각선 속도 정규화, 최대 체력 5. 각 구간에 무작위 가시 3개가 있습니다.
- 출발점 주변 반경 64는 가시가 침범하지 않는 안전 구역입니다. 출발 구간의 가시는 위쪽에 배치하여 시작 직후 충돌을 방지합니다.
- 이동 가속도는 `220 + 420 × (1 − 현재 속도 / 최대 속도)²`입니다. 출발 시 640으로 강하게 가속하고 최대 속도에 가까워질수록 220까지 감소합니다. 최대 속도 110까지 약 0.34초, 감속도 840으로 정지까지 약 0.13초가 걸립니다. 대각선에도 같은 가속도와 최대 속도가 적용됩니다.
- 플레이어는 주변보다 조금 밝은 회색(`#8b9690`)으로 표시하며, 테두리와 피격 표시도 밝기를 낮춥니다.
- 시야의 **지름**은 정지 시 플레이어 지름의 4배, 걷기 최대 속도 시 약 3.41배(기존 값 유지), 달리기 최대 속도 시 2.75배입니다. 실제 속도에 따라 구간별로 자연스럽게 감소합니다. 가장자리에서 가시가 흐려지고 시야 밖에는 표시되지 않습니다. `IDLE_VIEW_DIAMETERS`, `WALK_VIEW_DIAMETERS`, `RUN_VIEW_DIAMETERS` 상수로 조정합니다.
- 가시는 원형 바닥과 테두리 안에 표시합니다. 원의 바깥 경계가 실제 함정 피격 범위(반경 11)이며, 플레이어 원과 겹치면 피해를 받습니다. 한 번 닿은 함정은 갈색으로 표시됩니다. 피격 범위 표시 역시 시야 안에서만 보입니다.
- 맵 아래쪽에서 출발하여 위쪽 끝에 도달하면 완료합니다. 구간 번호는 아래에서부터 1로 시작합니다. 카메라는 플레이어의 세로 위치를 화면 중앙에 유지하며, 표시 배율은 최대 1.35입니다(플레이어 지름 약 43px).
- 위 끝 도달, 체력 소진, 진행 중 초기화 시 기록을 자동 다운로드합니다. 자동 다운로드가 차단되면 최근 플레이 기록 저장 버튼을 사용하세요.
- JSON에는 종료 사유, 남은 체력, 닿은 함정 수와 ID, 맵과 함정 좌표, 시간별 실수 좌표 동선, WASD와 스페이스바 입력 이벤트가 포함됩니다. 좌표는 왼쪽 위가 원점이고 아래 방향이 +y입니다.
- 창 전환 시 입력이 해제되며, 비활성 탭의 시간은 동선에 소급 적용하지 않습니다. 모바일 조작과 가상 패드는 포함하지 않습니다.

상수는 `game.js` 상단에서 조정할 수 있습니다.
